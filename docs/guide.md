[JPetStore 6 프로젝트 아키텍처 가이드]

이 프로젝트는 MyBatis 3, Spring 5, Stripes 프레임워크로 구성된 웹 애플리케이션이며, 다음과 같은 레이어 구조를 따른다.

1. domain 레이어 (src/main/java/.../domain)
   - 비즈니스 도메인 객체(엔티티) 위치
   - 예: Account, Item, Order 등
   - 필드 추가/삭제 같은 단순 변경은 대체로 영향 범위가 좁음 (영향도: 하~중)

2. mapper 레이어 (src/main/java/.../mapper, src/main/resources/.../mapper)
   - 인터페이스(Java)와 SQL 매핑 XML로 구성
   - 실제 DB 쿼리를 정의하는 곳이라, 여기 변경은 여러 화면/기능에 연쇄적으로 영향을 줄 수 있음 (영향도: 중~상)

3. service 레이어 (src/main/java/.../service)
   - 비즈니스 로직 처리
   - 여러 화면(Action)에서 공통으로 호출되는 경우가 많아, 호출하는 곳이 몇 군데인지에 따라 영향 범위가 달라짐 (영향도: 중)

4. web/actions 레이어 (src/main/java/.../web/actions)
   - 화면 요청을 처리하는 프레젠테이션 로직
   - 특정 화면 하나에 국한된 경우가 많음 (영향도: 하~중)

5. WEB-INF 설정 파일 (web.xml, applicationContext.xml)
   - 애플리케이션 전역 설정 (프레임워크 초기화, 트랜잭션, 보안 등)
   - 애플리케이션 전체에 영향을 줄 수 있어 변경 시 각별한 주의 필요 (영향도: 상)

6. JSP 화면 (src/main/webapp/WEB-INF/jsp)
   - 사용자에게 보여지는 화면(View) 로직
   - 해당 화면 단독으로 영향이 제한되는 경우가 대부분이나, 클라이언트 검증 로직 변경은 서버 측 검증 미비와 결합될 경우 보안/데이터 무결성 이슈로 이어질 수 있음 (영향도: 중)

7. docs 경로 (프로젝트 문서)
   - docs/guide.md (이 가이드 문서 자체): 영향도 분석 AI가 참조하는 판단 기준 문서이므로, 변경 시 영향도 판단 기준 자체가 바뀌는 것과 같아 영향도: 상
   - 그 외 /docs 하위 문서 (예: 배포리스트,산출물 등): 참고용 정보성 문서로 변경 시 영향도: 중
